# 读者模型: 研究问题文档

这个目录是**人类唯一的输入口**。周报靠它决定什么值得读。

## 规则

1. **只有你能改这里的文件。** agent 和 pipeline 永远只读不写。仓库里有一个测试专门守这条。
2. 每份 `q*.md` 是一个研究问题。文件名就是 question id (`q1` .. `q5`)。
3. 五个小节标题固定, 不能改名也不能增删:
   `## 当前看法` / `## 支持证据` / `## 反对证据` / `## 什么会让我改看法` / `## 想做的实验`
4. 第一行必须是 `# Q<n>: <标题>`。标题会出现在周报的理由里。

## delta 打分是什么

对每一条候选内容, 打分器回答的**不是**"这条跟我的方向相关吗", 而是:

> 这条内容会不会让我改动上面某一栏的文字?

所以一篇跟你方向高度相关、但只是复述你已经写在"当前看法"里的东西的论文, 应该得低分。
一篇方向稍远、但直接命中你"什么会让我改看法"那一栏的论文, 应该得高分。

`## 什么会让我改看法` 写得越具体, 打分越准。这一栏空着的问题, 基本只能靠"反对证据"来判。
